本文件定义了在本工作区（`d:\mes\mes`）内进行所有代码开发、架构设计、业务实施与文档编写时的**最高指引准则**。

## 核心宗旨：企业全局制造升级与个人工业 AI 全栈资产沉淀双赢

本项目不是孤立的“单点仓库改造”或“外包式代码堆砌”，而是基于企业真实离散制造场景（伺服电机/精密模组/伺服驱动器）的 **全流程工业 MES 建设与企业级 AI 深度落地工程**。

所有交互必须遵循以下三大支柱、工程军规（详见 [.agents/rules/fde-collaboration-principles.md](file:///d:/mes/mes/.agents/rules/fde-collaboration-principles.md)、[.agents/rules/windows-bat-standards.md](file:///d:/mes/mes/.agents/rules/windows-bat-standards.md) 及 [.agents/fde-growth/FDE项目全生命周期指导方针.md](file:///d:/mes/mes/.agents/fde-growth/FDE项目全生命周期指导方针.md)）：

### 1. Echo 维度（穿透制造全流程痛点，拒绝局部偏科）
- **覆盖制造全生命周期**：指导视野绝不仅限于仓储与物料，必须贯穿 **工艺工程(PLM/MBOM) ➔ 生产计划(PMC/APS) ➔ 仓储物流(WMS) ➔ 车间执行(SFC/报工) ➔ 质量管控(QMS) ➔ 设备工装(TPM)** 六大核心域。
- **立足车间实操与人机交互现实**：制造现场以扫码枪、工位工控机、电子看板、移动 PDA 为主，严禁设计脱离工人习惯的繁琐表单；任何 AI 落地必须符合现场操作节奏（防呆防错、秒级反馈）。
- **管理层 ROI 穿透**：每个功能与 AI 场景必须回答：提升了哪项关键指标（交期达成率、不良率、人均产出、库存周转天数、排产耗时）。

### 2. Delta 维度（高质量系统架构与全厂 AI 落地矩阵）
- **系统工程规范**：严格遵循 Spring Boot 3.x + Vue 3 + MySQL + Docker 架构，保障高并发报工、复杂事务一致性与网络离线容灾能力。
- **与老系统（ERP）的防腐边界**：坚守“MES 管生产实绩与工位流转，ERP 管财务与进销存”的单向防腐层原则，确保主数据唯一真实源（SSOT）。
- **构建全厂 AI 应用矩阵（Tool-First & Agent-Ready）**：
  - **研发/售后中枢**：基于 RAG 的伺服技术支持与排障知识库；
  - **生产工位中枢**：工序作业指导、防漏防呆与报工辅助 Copilot；
  - **质量追溯中枢**：一机一码正反向穿透溯源与不良根因分析 Agent；
  - **经营决策中枢**：面向高管的自然语言实时看板与交付风险预测（Text-to-SQL / BI Agent）。

### 3. FDE 资产化维度（工程经验复利与个人价值跃迁）
- **核心工程治理原则：“运行时单体，代码态平台”**：
  - **物理部署死守单体**：本体逻辑与映射机制直接编译在 MES 内部，车间 PDA 扫码享受微秒级本地数据库事务与内存直接调用，保障 100% 工业零容错与断网自治；坚决不启动独立的外部运行态微服务，规避网络延迟与分布式事务灾难。
  - **代码设计坚守平台**：核心领域模型保持 100% 纯洁（如独立映射表 `mes_md_item_mapping`），无任何特定客户或老系统专有字段，随时具备作为通用 SDK 打包带走的能力。
- **制造全域本体沉淀（Manufacturing Ontology）**：不仅沉淀物料语义，更持续完善“工序-工位-设备-模具-BOM-质检项”的全要素工业知识图谱。
- **高价值工业 Skill 封装**：将工艺路径推荐、动态排产冲突消解、负库存纠偏、MRB 评审流转等提炼为可复用的工业 Skill。
- **沉淀个人可携带的“四大 FDE 背包武器”**：
  1. **制造本体元模型 SDK**：纯 Java/JSON Schema 离散制造模型（Part/Assembly/Routing/MBOM/四级仓位）；
  2. **工业 AI 标准动势工具集**：包含齐套试算、防呆阻断、排产求解的 Spring AI `@Tool` 集合；
  3. **通用异构防腐连接器**：不动客户老系统、两周内实现账实对齐与负库存冲销的 ACL 模式；
  4. **5 天 MVD 单品穿透 SOP**：从单品聚焦到高管见证的全套现场交付作战手册。
- **文档与工程资产隔离**：业务落地记录沉淀于 `docs/02-实施进度/`，个人成长与 AI 治理固化于 `.agents/`，确保成果可追溯、个人有复利。

## 项目 FDE 八大实战军规（执行红线）

无论任何会话接续，Agent 必须强制遵守以下执行红线：
1. **深水区法则**：死守 95%~99% 生产可用性，硬规则兜底最后 1% 工业零容错，绝不做 80% 玩具 Demo。
2. **双向蒸馏机制**：现场隐性经验 ➔ 规则库与 Agent；现场特化代码 ➔ 平台组件；坚守脚手架原则与 80/20 双轨考核。
3. **制造业务本体论**：以 13 类极简物料为语义层（SSOT），Spring AI `@Tool` 为动势层，三级仓位为动态层；践行“运行时单体，代码态平台”，死守领域纯洁度与微秒级车间响应。
4. **单品试点穿透制**：践行 MVD 三军规（真实数据无例外、缩范围不缩深度、周级硬截止），以管状直线电机单品打穿端到端闭环，严禁全量脏数据一刀切导入。
5. **现场零阻力交互**：车间端去键盘化（PDA 扫码 + 一键确认大按钮），把 AI 提问封装为一键动作，践行小时级热修复。
6. **读旧写新单向防腐**：编码继承老 ERP，MES 独立自治，完工扫码后单向异步回写 ERP 平账，彻底消除负库存。
7. **评估体系先行**：考题前置，业务专家任评委，测试集通过率 > 90% 方可上线；AI 坚持副驾驶模式。
8. **三级复制杠杆**：逐级沉淀知识手册 ➔ 工具组件 ➔ 本体平台，后续品类定制递减 70%，汇报穿透财务与经营 ROI。
