## 一、 德米萨 ERP 现状摸底与实盘数据分析

在启动自研 MES 基础数据建模前，技术团队对公司现行“德米萨 ERP”底库与导出的物料进销存数据进行了深度穿透式诊断。德米萨 ERP 承载了公司多年的采购、库存与财务核算，但底层数据存在严重的账实脱节与分类混乱。

### 1.1 核心物料类别的库存账面汇总

通过对 ERP 导出全量库存汇总，核心大类的账面结存呈现出极端异常：

## 二、 负库存现象的根本症结诊断

ERP 中为何会出现高达数千件的“负库存”？经过现场调研与流程比对，锁定了根本症结：

```
【传统业务漏洞流程】
客户下单 ──► ERP 录入销售订单 ──► 仓库点击【销售出库】(强制扣减库存，变成负数！)
                                          ▲
                                   [此处发生断层！]
                                          ▼
车间排产 ──► 工人手工领料 ──► 组装测试 ──► 包装直接发货 (从未在 ERP 中创建【生产完工入库单】)
```

1. **出库强制扣减，完工从未入库**：
   - 销售部发货时，ERP 支持“允许负库存出库”或仓库直接点了销售出库单，系统自动扣减库存；
   - 车间现场生产组装完成后，由于德米萨 ERP 缺乏现场扫码和工单报工功能，**从未录入过“生产完工入库单”**；
   - 结果导致底层数据库**只有出库记录，没有入库记录**，销售量越大，账面负数越庞大。
2. **“以销定产”缺乏在制品流转控制**：
   - 生产过程完全处于黑盒状态，物料领料凭手工单据，中间定子总成、动子总成报废或在制无法统计；
   - 最终出库的到底是整机、还是散件动定子套件，在 ERP 中未做严格交付物区分。

## 三、 ERP 历史物料的“大杂烩”分类混杂

除了负库存外，德米萨 ERP 的分类逻辑存在严重的业务混淆，直接导致无法直接导入 MES：

### 3.1 外购光学原材料 vs 车间装配半成品
* **ERP 现象**：在 `圆光栅` 分类下，既有外购供应商直接送来的 `玻璃码盘`（结存 +2055）、`镀铬码盘`（结存 +632），又有车间工人经过定心装配、紫外光固化贴合后的 `光栅环(IESR17)`（结存 -841）和 `ICDM-11-256 码盘总成`。
* **业务硬伤**：
  * 外购玻璃基片是**采购原材料**（无 BOM，采购收货入库）；
  * 光栅环是车间工位组装的**半成品 WIP**（需要消耗玻璃片与金属轮毂，走组装工序，有独立的报工工时）；
  * 如果全部堆在“圆光栅”成品分类下，MES 无法排产半成品工单。

### 3.2 DD马达整机 vs 无框动定子套件形态
* **ERP 现象**：客户大量采购 `ICR-40-0485 动定子`（套件）与 `定子/线圈`（备品配件），在 ERP 中全部叫“DD马达”。
* **业务硬伤**：
  * 有的客户直接买整机（带外壳、轴承、编码器，插电即用，计量单位：`台`）；
  * 有的自动化设备客户只需要无框动定子（动子+定子成对采购，自行装入机械臂，计量单位：`套`）；
  * 车间售后维修或单独补单只需要定子线圈（计量单位：`件`）；
  * MES 中必须细分为 `DD马达整机`、`动定子套件` 与 `定子/线圈外售散件`，否则 BOM 选型无法匹配。

### 3.3 编码器工具与备件单独设立
* **ERP 现象**：ERP 存在大量 -9350 结存的编码器配件：`IND140712 光栅磁零位`、`ICDM-30 端部压块`、`光栅/磁栅安装块`、`校准工装`。
* **业务硬伤**：这些物料随整机配套发出或单独外售，但在 ERP 中被随手归档，缺少分类管控。必须独立归入 `产成品 > 编码器 > 编码器工具`。

### 3.4 非实物工程费用混入物料档案
* **ERP 现象**：物料编码中赫然包含 `ICDM-30-带孔母版费`，单位为“次”，结存为 0 或负数。
* **业务硬伤**：这是供应商光刻开模工程费（NRE），纯属财务报销与采购开票项，绝不是车间物理制造的零部件，严禁进入 MES 排产。

## 四、 针对性实施策略与破局方案

面对 ERP 的上述历史包袱，确定了以下技术实施原则：

1. **绝不动德米萨 ERP 底层结构**：
   - 不修改 ERP 现有的任何数据表，不重构 ERP 分类，避免触动旧版财务审计与历史账目；
   - 避免向德米萨厂商提出昂贵的定制开发需求。
2. **在 MES 中建立全新规范体系**：
   - 采用 6 大工艺阶段树形分类，全量梳理原材料、半成品与产成品；
   - 采用 2~4 字极简短名，确保现场工人与 UI 操作极致清晰。
3. **设置防腐层（ACL）与平账机制**：
   - MES 与 ERP 保持物料编码绝对一致；
   - MES 车间完工下线后，通过防腐层自动调用/回写德米萨 ERP“完工入库单”，逐步冲平 ERP 历史负库存。
4. **单品切入，逐步推进**：
   - 不搞全厂一刀切，先锁定 1 款主力产品（如 DD马达 ICR 系列）作为试点，跑顺全流程后再全量切换。
